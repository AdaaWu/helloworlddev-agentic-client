## 本次目標

```
Vue 的部分(前端) : 解析 SSE 文字格式，依 event 分派 callback
```

1. stream 一次收到的文字不一定剛好是一則完整的訊息，要先暫存起來，再用 `\n\n` 切出一則一則的訊息
2. 每則訊息再用 `\n` 切成多行，每行是 `欄位: 值` 的格式，欄位有 `id`、`event`、`data`、`retry`
3. 依照 `event` 的種類呼叫對應的 callback，例如 `message` -> `onMessage`（時間有限，至少把 `message` 做通）
4. 空字串的訊息要略過

## 完成後你會看到

按下按鈕後，console 每秒會印出一行 :

```
收到的訊息 : 2026-10-11T10:00:00+08:00
```

印出來的只有 `data` 的內容，不會再看到 `event:`、`data:` 這些欄位名稱。
