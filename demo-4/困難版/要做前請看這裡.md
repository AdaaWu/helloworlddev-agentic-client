這裡是困難版挑戰...就這樣

這裡拿到的前後端是上一個 demo 的解答，請從這裡開始完成本次目標。（前端已經幫你做好了，這次只需要改後端）

## 本次目標

```
Golang 的部分(後端) : 後端改用 `AgentStep` 的方式把訊息傳出去
```

1. 讀取前端送來的 JSON request body，格式是 `{"message": "..."}`
2. 把要回覆的文字切成一個字一個字，每隔一小段時間（例如 80ms）送出一則 SSE 訊息
    - 格式 : `id: <第幾則>\nevent: message\ndata: <這次的字>\n\n`
3. 全部送完後，再送一則 `event: done` 的訊息告訴前端結束了
4. 使用者斷線（`r.Context()` 結束）時要停止送出

## 完成後你會看到

在前端輸入框打字並按下送出，AI 的回應會一個字一個字出現，例如 :

```
收到的訊息 : Hi
```

也可以先用 curl 測試後端 :

```sh
curl -N http://localhost:8080/sse -X POST -d '{"message": "Hi"}'
```
