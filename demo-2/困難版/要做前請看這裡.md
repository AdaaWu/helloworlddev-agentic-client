這裡是困難版挑戰...就這樣

這裡拿到的前後端是上一個 demo 的解答，請從這裡開始完成本次目標。（後端已經幫你改成 `POST /sse` 了）

## 本次目標

```
Vue 的部分(前端) : EventSource -> fetch，並且把後端的 stream 結果 console 出來
```

1. 畫面上放一個按鈕，按下去之後用 `fetch` 對 `http://localhost:8080/sse` 發出 **POST** 請求
2. 不要用 `response.json()`，改成讀取 `response.body` 這個 `ReadableStream`
3. 收到的是 `Uint8Array`，要 decode 成文字後再 `console.log`
4. 結束時記得把 reader 釋放掉

## 完成後你會看到

按下按鈕後，console 每秒會印出一段像這樣的文字 :

```
event: message
data: 2026-10-11T10:00:00+08:00
```
